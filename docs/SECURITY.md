# 数据边界与使用约束

- 服务绑定 `127.0.0.1`，严格检查 Host/Origin；写操作检查随机 CSRF header。没有 CORS、云 API、远程脚本、第三方字体、遥测或自动更新。
- 页面使用 textContent 呈现输入；原型转义 HTML、禁止脚本和表单提交。导出 CSV 防公式注入。MVP HTTP 不是生产服务，不增加公网或局域网监听选项。
- 默认不调用任何模型。显式启用后固定本机 Ollama，禁用代理和重定向；发业务内容前检查云功能禁用与本地权重元数据，未知或远程模型拒绝；`local_sensitive` 分类拒绝进入模型。分类依赖人工声明，不能保证自动识别所有客户信息。不得把真实客户材料传给助手、GitHub 或云服务。
- AI 建议不执行代码、不访问 URL、不自动应用。输入中指令作为不可信业务材料。提示词约束只能降低提示注入影响，不能保证模型完全遵循；输出需要人工核实。
- SQLite、导出与临时浏览器草案留在本机。数据库无内置加密；使用受控设备和磁盘权限。关闭服务后复制数据库可备份。导出包包含历史内容，历史修订里可能仍有已移除信息；外发前人工脱敏。
- 所有测试、截图和演示只含合成数据。运行日志不记录请求体/模型 prompt。仓库忽略 data/、exports/、env 文件，但忽略规则不能阻止人为强制提交，发布前仍检查待提交清单。
- 个人操作者与签署人是手填字段，不提供认证、角色授权或不可否认签名。拥有本机访问权的恶意进程和数据库文件所有者不在当前威胁边界内。签署不表示真实会计或税法合规，也不自动授予部署权限。
